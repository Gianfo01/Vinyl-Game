# Lote 07: pedidos de peças

- **Pintura facial / maquiagem de palco** (`face.paint`: estrela, morcego, gato, raposa, corpse paint). Para KISS (Paul Stanley, Gene Simmons, Ace Frehley, Peter Criss, Eric Carr) e King Diamond. Por enquanto usei pele `#e8e0d8`, que dá base branca, mas sem os desenhos.
- **Flauta transversal** (pose `flute` + prop). Para Ian Anderson (Jethro Tull), que hoje está com sax. Também serviria a Dennis Thomas (Kool & the Gang).
- **Chapéu-coco / bombín** (`hat.style: bowler`). Para Joaquín Sabina, que hoje está de fedora.
- **Sombrero de charro** (aba muito larga, copa alta, bordado prateado). Para Jorge Negrete, que hoje está de `cowboy` com faixa prateada.
- **Chapéu bucket** (`hat.style: bucket`). Para Oleh Psiuk (Kalush Orchestra), o bucket rosa do Eurovision 2022; hoje está com `beanie` rosa.
- **Óculos de veneziana / shutter shades**. Para Kanye West em 2007-08; hoje está com `dark` de armação branca.
- **Saia de bananas**. Para Josephine Baker; hoje está com `skirt` amarela.
- **Capuz** (hood) no `jumpsuit`. Para Kylie Minogue em 2001 (Can't Get You Out of My Head).
- **Sári / áo dài** (vestido com faixa diagonal ou fenda lateral). Para Kanan Devi e Khánh Ly; hoje estão com `gown`/`dress`.
- **Gibson Flying V** (`prop.shape: v`). Para K. K. Downing; hoje está com corpo Strat.
- **Pedestal de ossos / cruz** (microfone do King Diamond).
