# Lote 06 — pedidos de peças

- **Quepe de marinheiro** (Hans Albers, 1944): hoje usa `cap`, que lê como boné de beisebol.
- **Chapéu peludo "buffalo hat"** (Jay Kay / Jamiroquai, 1996): hoje usa `beanie` marrom.
- **Pandeiro** como prop (Jackson do Pandeiro): hoje usa a pose `drums` com baquetas.
- **Kepi militar / quepe de farda** (James Reese Europe, 1918): ficou sem chapéu.
- **Fila / peci** (gorro cilíndrico africano / indonésio — Haruna Ishola, Ismail Marzuki, Vovô do Ilê): hoje usa `beanie`.
- **Poncho andino** (Inti-Illimani): hoje usa `tunic` listrada.
- **Violão canhoto** (`guitar_lefty` com `acoustic`) para Gurrumul, que tocava violão invertido; ficou com `guitar` destro.
- **Maracas** (Bez / Happy Mondays): ficou com `arm_up` sem objeto.
- **Roupão de banho** (Harry Nilsson, capa de 'Nilsson Schmilsson'): hoje usa `coat_long` vinho.
