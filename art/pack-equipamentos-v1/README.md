# Pacote de equipamentos v1 (arte-fonte)

29 PNGs (RGBA, ~1250 px) que definem o estilo visual do Masters: pixel art HD, vista 3/4, luz de cima à esquerda,
contorno escuro quente, sombras arroxeadas, luzes quentes, mogno/latão/vinho. `_folha.png` mostra todos juntos.
`01_fonografo_1890.png` veio corrompido no envio original e falta aqui.

Os personagens seguem o mesmo estilo e são gerados pela skill `.claude/skills/masters-artist-sprites/`
(regras do estilo no SKILL.md; exemplos em `docs/arte-artistas/`).
